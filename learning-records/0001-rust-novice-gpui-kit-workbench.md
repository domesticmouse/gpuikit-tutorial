# Rust Novice Baseline & Antigravity Workbench Mission

The learner is a Rust novice who wants Rust concepts (ownership, borrowing, structs, enums, traits, closures, and `Entity<T>`) introduced inline as they appear in real code, rather than front-loaded in abstract exercises. Their concrete goal is to build fast Markdown and conversation editing interfaces around `antigravity-sdk-rust`, starting by re-implementing project-based agentic coding workbench patterns in GPUI Kit.

## Evidence
- User stated: "I'm a rust novice, I'll need to have rust concepts introduced as they appear" and "I'm building apps around https://crates.io/crates/antigravity-sdk-rust and I want an ability to easily and quickly edit makdown files / conversations."

## Implications
- Every lesson must unpack newly introduced Rust syntax alongside GPUI Kit APIs.
- All companion code in `apps/` should model realistic conversation turns and Markdown documents from Lesson 0001 onward.
