This hands-on course teaches **GPUI Kit** (`longbridge/gpui-kit`) and foundational **Rust** side by side. Every lesson builds a runnable, unit-tested step of an **Antigravity Markdown & Conversation Workbench** in `./apps/`.

:::callout title="How Each Lesson Works"
1. **Read & Simulate**: Unpack each new Rust keyword and GPUI Kit layer block by block, then inspect the full runnable file.
2. **Practice Retrieval**: Complete inline fill-in-the-blank labs and equal-length quizzes to lock concepts into long-term memory.
3. **Verify Locally**: Run `cargo test` and `cargo clippy --all-targets -- -D warnings` inside the lesson's `apps/` directory.
:::
